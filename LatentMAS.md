$W_{in}$ input token embedding matrix
$W_{out}$ output token embedding matrix

Theoretical Justification for W_a;
$W_a$ minimizes the distributional gap between the distribution of token embeddings and the distribution of aligned embeddings.

Let $P_e$ and $P_h$ be the distribution of token embeddings $e$ and the hidden embeddings $h$, respectively. We assume that $P_e$ and $P_h$ can be generated by $e = W_{\text{in},x}$ and $h = W_{\text{out},x}$, respectively, where token $x$ follows an underlying token distribution $x \sim P_V$. For an alignment matrix $W_a$, the aligned embedding distribution $P_{\hat{e},W_a}$ is

$$P_{\hat{e},W_a} : \hat{e} = hW_a, \quad h \sim P_h. \tag{9}$$

Our goal is to minimize the distance between the aligned embedding distribution $P_{\hat{e},W_a}$ and the token embedding distribution $P_e$, which we measure via the [[Wasserstein distance]]:

$$d_{\text{Wasserstein}}(P_{\hat{e},W_a}, P_e) := \inf_{\gamma \in \Gamma(P_e, P_{\hat{e},W_a})} \sqrt{\underset{(\hat{e},e) \sim \gamma}{\mathbb{E}} \left[ ||\hat{e} - e||_2^2 \right]}, \tag{10}$$

where $\Gamma(P_{\hat{e},W_a}, P_e)$ is the set of all couplings of $P_e$ and $P_{\hat{e},W_a}$.
