(aka monogenous group) is a [[Groups|group]] $C_n$ that can be generated by a single element.
- abelian
- subgroups are cyclic
- all infinite cyclic groups isomorphic to $\mathbb{Z}$
- all finite cyclic groups isomorphic to $\mathbb{Z}_n$
- eg. $\mathbb{Z}$, $\mathbb{Z}_n$

A group G is **cyclic** if there exists an element $g \in G$ such that: $G = \langle g \rangle$
This means every element of G can be written as:
- $g^n$ (multiplicative notation), or
- $ng$ (additive notation),
for some integer n
 -The element g is called a generator of the group.

If n is prime, then G is a [[Simple Group]]
