Type of non-[[Bravais Lattice]]

Construction

Start w/ triangular bravais lattice: 
	$a_1 = (1,0), \quad a_2 = \left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$
	$R = n a_1 + m a_2$
	which generate a rectangular grid
Add a 2 poitn basis place two atoms
	A at: $R$
	B at: $R + \delta$ where $\delta = \left(\frac{1}{3}a_1 + \frac{1}{3}a_2\right)$



Alternative construction (graph viewpoint)

You can also define it as:
1) Start with a triangular lattice.
2) Remove every other bond pattern.
3) Keep only 3 nearest neighbors per node.
This produces:
- hexagonal tiling of empty space
- coordination number = 3

The honeycomb is a 2D [[bipartite graph]]
- two sublattices: A and B
- edges only connect A ↔ B
- no A–A or B–B edges


**Takeaway**
The honeycomb lattice is **not a Bravais lattice** because:
- A-sites cannot be translated into B-sites
- there are two inequivalent points per unit cell
