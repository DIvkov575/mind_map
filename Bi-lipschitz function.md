- For a real number $K \geq 1$ if
	${\displaystyle {\frac {1}{K}}d_{X}(x_{1},x_{2})\leq d_{Y}(f(x_{1}),f(x_{2}))\leq Kd_{X}(x_{1},x_{2})\quad {\text{ for all }}x_{1},x_{2}\in X,}$
	then f is called K-bilipschitz
- [[Lipschitz Continuity]]
- We say f is bilipschitz or bi-Lipschitz to mean there exists such a K. 
- A bilipschitz mapping is injective, and is in fact a [[Homeomorphism]] onto its image
- A bilipschitz function is the same thing as an injective Lipschitz function whose inverse function is also Lipschitz.
