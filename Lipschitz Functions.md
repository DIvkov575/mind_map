A Lipschitz function is a function whose rate of change is globally bounded by a constant.

Let $f : X \to Y$ be a function between metric spaces with a distance function d
f is Lipschitz if there exists a constant $L \ge 0$ such that for all $x_1, x_2 \in X$
$$d(f(x_1), f(x_2)) \le L \, d(x_1, x_2)$$
L is called the Lipschitz constant
in $\mathbb{R}$ $|f(x) - f(y)| \le L |x-y|$


Implications
- bounded AROC
- Lipschitz functions are [[Uniformly Continuous]]
