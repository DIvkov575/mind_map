The Cerebral Cortex is the thin outer layer of neural tissue covering the two hemispheres of the [[Cerebrum]]
- **Thickness:** ~2–4 mm
- **Structure:** highly folded sheet ([[Gyri]] and [[Sulci]])
- **Composition:** [[Gray Matter]] (neuronal cell bodies, dendrites, synapses) — see [[Neuron Model]] for how the individual units in this tissue get abstracted mathematically

| Function           | Description                                    |
| ------------------ | ---------------------------------------------- |
| sensory processing | interpreting visual, auditory, tactile signals |
| motor control      | planning and initiating voluntary movement     |
| cognition          | reasoning, planning, decision-making           |
| language           | comprehension and production                   |
| memory             | interaction with other brain systems           |
Lobes

| Lobe      | Primary roles                                 |
| --------- | --------------------------------------------- |
| frontal   | planning, motor control, executive function   |
| parietal  | spatial processing, somatosensory integration |
| temporal  | auditory processing, memory                   |
| occipital | visual processing                             |

In MRI analysis (e.g., using **FreeSurfer**):
- the cortex is modeled as a **folded 2-D surface embedded in 3-D space**
- boundaries between [[Gray Matter]] and [[White matter]] define the **cortical surface meshes**
- data (e.g., [[fMRI]] activation) are often analyzed **along this surface**![Cerebral Cortex: What It Is, Function & Location|417](https://my.clevelandclinic.org/-/scassets/images/org/health/articles/23073-cerebral-cortex)
