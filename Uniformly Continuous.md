A function $f : X \to Y$ between metric spaces is uniformly continuous if
$$
\forall \varepsilon > 0 \; \exists \delta > 0 \text{ such that } 
\forall x,y \in X,\;
d(x,y) < \delta \Rightarrow d(f(x),f(y)) < \varepsilon.
$$
The key property is that $\delta$ depends only on $\varepsilon$, not on the points $x,y$.

Eg.
- Linear mx + b
- [[Lipschitz Functions]]
- [[Continuous]] functions on [[Compact]] intervals
- Square root (not Lipschitz)
