Given polygon defined by n points ($(x_0, y_0), (x_1,y_1) \dots (x_n, y_{n})$ with $(x_n, y_n) = (x_0, y_0)$)

Draw horizontal line (extending inftly in a lateral direction)
Count number intersections with polygon edges (not vertices)
even # intersections $\mapsto$ outside 
odd # intersections $\mapsto$ inside
