A contraction mapping is a function that strictly “shrinks” distances between points in a [[Metric Space]]
	
Let (X,d) metric space. [[Lipschitz Functions]] $f: X \to X$ is a contraction if there exists a constant $0 \leq c < 1$ such that for all $x, y \in X$
$$d(f(x), f(y)) \leq c \cdot d(x, y)$$
c is called the contraction factor
