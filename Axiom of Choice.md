If you have a collection of nonempty sets, you can choose one element from each set

Asserts existence of a function even if we can't construct it

Suppose infinite many nonempty sets: $S_1, S_2, \cdots$
and each set contains arbitray objects with no obvious way to pick an element. AC says there still exists $f(i) \in S_i$ that picks one element from each set simultaneously.
