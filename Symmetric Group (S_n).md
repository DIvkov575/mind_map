Sn​ is the group of all permutations of an n-element set usually {1,2,…,n}. A permutation is a bijection from the set to itself.

A transformation is a _symmetry_ of an object if applying it does not change the object in any meaningful way

- **Structure:** extra data or relations on a set  
    (order, distance, algebraic operations, labels with meaning, geometry, etc.)
- **Permutation:** a **bijection** of the underlying set

The group structure comes from function composition
- **Elements:** permutations σ:{1,…,n}→{1,…,n}
- **Operation:** composition (σ∘τ)(i)=σ(τ(i))
- **Identity:** the identity permutation e(i)=i
- **Inverse:** each permutation has an inverse bijection
- **Associativity:** inherited from function composition
